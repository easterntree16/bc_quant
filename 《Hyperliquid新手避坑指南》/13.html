第十三章：模拟交易——测试网使用、模拟资金配置、策略回测

说实话，我见过太多新手一上来就冲进主网。

结果呢？爆仓、被割、心态崩了。

我自己在Hyperliquid上踩过的坑，至少有三分之一是可以在测试网里提前发现的。可惜当时没人告诉我这些。

今天这章，我就把测试网的正确用法、资金配置的潜规则、还有回测的那些坑，一次性讲清楚。

13.1 测试网到底有什么用？

很多人觉得测试网就是「模拟器」，随便玩玩就行。

嗯，这个想法很危险。

测试网的核心价值，不是让你熟悉界面——那五分钟就够了。它的真正作用是：

  • 验证你的策略逻辑：你的开仓条件、止损设置、仓位管理，在真实市场里会不会出bug？
  • 测试网络延迟和滑点：Hyperliquid的订单簿深度、撮合速度，在测试网里能提前感受
  • 心理建设：模拟资金亏完，总比真金白银亏完强吧？

我个人习惯：每次开发新策略，先在测试网跑至少100笔交易。不是看赚了多少，而是看「会不会出现我没预料到的异常情况」。

13.2 测试网使用指南

Hyperliquid的测试网地址和主网不同。你需要：

  1. 访问测试网入口（通常是 testnet.hyperliquid.xyz）
  2. 连接测试网钱包（别用主网钱包！）
  3. 从水龙头领取测试代币

这里有个坑：测试网的流动性远不如主网。你挂一个单，可能半天没人接。所以测试网更适合做「逻辑验证」，而不是「滑点测试」。

我曾经在测试网跑了一个高频策略，回测数据漂亮得不行。结果上主网第一天，滑点直接吃掉了我一个月的利润。为什么？因为测试网的订单簿深度是假的。

13.3 模拟资金配置：别太「大方」

测试网一般会给你100万模拟USDC。

很多人一看：哇，这么多钱！然后全仓干进去。

这其实是个坏习惯。你想想看，主网上你只有1000U，你敢全仓吗？不敢吧？那为什么测试网就敢？

我的建议：模拟资金配置应该模拟你的真实资金规模。

真实资金 模拟资金建议 理由
1000 USDC 1000 模拟U 模拟真实仓位压力
10000 USDC 10000 模拟U 测试杠杆和风控
100000 USDC 50000 模拟U 大资金需要更保守

说白了，测试网不是让你过瘾的，是让你「犯错」的。资金规模越真实，犯错的教训越有价值。

13.4 策略回测：别被数据骗了

回测是每个交易员的必修课。但Hyperliquid上的回测，有几个特殊的地方需要注意。

13.4.1 回测数据源

Hyperliquid的链上数据是公开的。你可以从Dune Analytics或者直接通过API拉取历史K线数据。

# 伪代码示例：拉取Hyperliquid历史数据
import requests

url = "https://api.hyperliquid.xyz/info"
payload = {
    "type": "candleSnapshot",
    "coin": "BTC",
    "interval": "1h",
    "startTime": 1700000000000,
    "endTime": 1705000000000
}
response = requests.post(url, json=payload)
data = response.json()

嗯，这里要注意：Hyperliquid的API返回的数据格式和中心化交易所不太一样。时间戳是毫秒级的，价格是字符串格式。我刚开始写回测脚本时，就因为类型转换问题，算出来的收益率差了10倍。

13.4.2 回测的三大陷阱

  • 幸存者偏差：你只回测了BTC，但你的策略可能只适合BTC的走势。换到ARB上试试？
  • 未来函数：回测时用了「未来数据」，比如用收盘价计算开仓信号。这在实盘中根本做不到。
  • 手续费忽略：Hyperliquid的吃单手续费是0.05%，挂单是0.02%。高频策略里，手续费能吃掉你一半利润。

我的经验：回测时，把手续费设置成实际值的1.5倍。这样如果回测还能赚钱，实盘大概率也能赚。如果回测刚好打平，实盘基本就是亏。

13.6 避坑指南汇总

最后，我把这些年踩过的坑，浓缩成几条实用建议：

  • 测试网不是游乐场：每次操作都当作实盘来对待。我见过有人在测试网用100倍杠杆乱开单，结果实盘也习惯性满仓——爆得很快。
  • 回测数据要清洗：Hyperliquid的链上数据偶尔会有空值或异常值。我写过一个脚本专门处理这些脏数据，不然回测结果会失真。
  • 模拟资金别太多：100万模拟U会让你产生「亏了也无所谓」的错觉。建议手动改成你真实资金的1-2倍。
  • 记录每一笔模拟交易：包括开仓理由、平仓原因、盈亏情况。这些记录比回测数据更有价值。

一句话总结：模拟交易不是走形式，是你和市场的第一次「正式对话」。认真对待它，主网会回报你。
