第七课：做多与做空——开仓方向选择、止盈止损设置、爆仓价计算

说实话，很多新手在Hyperliquid上亏钱，不是亏在行情判断上，而是亏在「方向搞反了」或者「爆仓了都不知道怎么算的」。今天这课，我就把做多、做空、止盈止损、爆仓价这些核心逻辑，掰开了讲清楚。

核心一句话：做多是「先买后卖」，做空是「先卖后买」。方向选错，神仙也救不了你。

一、做多与做空：开仓方向怎么选？

做多，说白了就是你觉得价格要涨。你买入，等涨了再卖出，赚差价。做空，就是你觉得价格要跌。你先借币卖出，等跌了再买回来还掉，赚差价。

嗯，听起来很简单对吧？但我在项目中遇到过不少新手，把做空理解成「反向做多」，结果开仓方向搞反，直接爆仓。这里我给大家一个口诀：

  • 看涨 → 做多 → 点击「Long」或「Buy」
  • 看跌 → 做空 → 点击「Short」或「Sell」

Hyperliquid的界面很清晰，开仓时会有「Long/Short」的切换按钮。我个人习惯是，开仓前先看一眼K线图，确认趋势方向，再动手。别急，急就容易出错。

小技巧：如果你不确定方向，可以先用小仓位试单。比如开0.1个ETH试试水，感受一下盘口深度和滑点。我刚开始做合约时，就靠这个办法少亏了不少钱。

二、止盈止损设置：别让盈利变亏损

止盈止损，是合约交易的「安全带」。不系安全带，你可能赚得爽，但一次失误就能让你回到解放前。

止盈（Take Profit, TP）：价格涨到目标位，自动平仓，锁定利润。
止损（Stop Loss, SL）：价格跌到某个位置，自动平仓，限制亏损。

Hyperliquid支持「限价止盈止损」和「市价止盈止损」。我个人建议用限价单，因为市价单在极端行情下可能滑点很大，你想想看，本来想止损在1000，结果成交在950，那多亏啊。

设置原则：

  • 止盈：建议设置在关键阻力位上方一点点，比如前高+0.5%
  • 止损：建议设置在关键支撑位下方一点点，比如前低-0.5%
  • 盈亏比：至少1:2，也就是赚2个点，亏1个点。这样胜率只要33%，你就能盈利

我曾经有一次做多BTC，没设止损，结果半夜一根针插下来，直接爆仓。嗯，从那以后，我开仓必设止损，哪怕只设一个很宽的位置，也比没有强。

三、爆仓价计算：你的仓位能扛多久？

爆仓价，就是你的保证金亏完、仓位被强制平仓的价格。Hyperliquid用的是「全仓模式」和「逐仓模式」，两种模式的爆仓价计算方式不一样。

3.1 逐仓模式爆仓价计算

逐仓模式下，你只亏这个仓位的保证金，不会影响其他仓位。公式如下：

做多爆仓价 = 开仓价 × (1 - 保证金率 / 杠杆倍数)
做空爆仓价 = 开仓价 × (1 + 保证金率 / 杠杆倍数)

举个例子：你开多1个ETH，开仓价2000U，10倍杠杆，保证金200U。

做多爆仓价 = 2000 × (1 - 1/10) = 2000 × 0.9 = 1800U

也就是说，ETH跌到1800U，你的仓位就爆了。你想想看，如果ETH跌到1800，你亏了200U，正好是全部保证金。

3.2 全仓模式爆仓价计算

全仓模式下，你的所有可用余额都作为保证金。公式稍微复杂一点：

做多爆仓价 = 开仓价 × (1 - (账户权益 - 维持保证金) / (仓位价值 × 杠杆倍数))
做空爆仓价 = 开仓价 × (1 + (账户权益 - 维持保证金) / (仓位价值 × 杠杆倍数))

嗯，这个公式看着有点吓人。但说白了，就是你的账户总资产减去维持保证金后，还能扛多少亏损。我个人建议新手先用逐仓模式，至少爆仓了你知道亏多少，心里有数。

⚠️ 重要提醒：Hyperliquid的爆仓机制是「部分减仓」而非「全部平仓」。当价格接近爆仓价时，系统会先减掉一部分仓位，降低杠杆，避免直接爆仓。但别指望这个机制能救你，它只是延缓爆仓时间。

五、实战案例：一次完整的做多操作

假设你现在想开多ETH，当前价格2000U，你打算用10倍杠杆，逐仓模式，保证金200U。

  1. 开仓：点击「Long」，输入开仓价2000U，杠杆10x，保证金200U。系统自动计算仓位大小为2个ETH（200U × 10倍 / 2000U = 1个ETH？不对，是200U × 10倍 = 2000U，2000U / 2000U = 1个ETH）。嗯，这里要注意，仓位大小 = 保证金 × 杠杆 / 开仓价。
  2. 设置止盈：你看到前高在2100U，设置止盈在2105U（前高上方一点点）。
  3. 设置止损：前低在1950U，设置止损在1945U（前低下方一点点）。
  4. 计算爆仓价：爆仓价 = 2000 × (1 - 1/10) = 1800U。也就是说，ETH跌到1800U，你的200U保证金就没了。

我的个人习惯：开仓后，我会立刻在手机上设置一个「价格提醒」，比如ETH跌到1850U时提醒我。这样即使我没盯着屏幕，也能提前知道风险。别问我为什么，问就是曾经爆仓爆怕了。

六、常见问题与避坑指南

  • 问：做空是不是比做多风险大？
    答：理论上，做多最多亏100%（跌到0），做空可能亏无限（涨到无限）。但实际上，加密货币波动大，做空的风险确实更高。我个人建议新手先做多，等熟悉了再做空。
  • 问：止盈止损设了，为什么没触发？
    答：可能是滑点问题。极端行情下，价格可能直接跳过你的止盈止损位。我建议用「限价单」而不是「市价单」，虽然成交慢一点，但至少不会滑点太多。
  • 问：爆仓价算出来是1800，为什么1805就爆了？
    答：因为还有「维持保证金」和「手续费」。实际爆仓价会比理论值更接近开仓价。嗯，这里要留点余量，我一般会在理论爆仓价上方加1%作为实际止损位。

⚠️ 避坑指南：我曾经有一次做空，没设止损，结果行情突然拉涨，我眼睁睁看着爆仓价越来越近，最后爆了。那种感觉，就像看着自己的钱被火烧一样。所以，开仓必设止损，这是铁律。

好了，这节课的内容就到这里。做多与做空，说白了就是方向选择的问题。方向对了，赚钱；方向错了，亏钱。但有了止盈止损和爆仓价计算，至少你能控制风险，不会一次亏光。记住，在Hyperliquid上，活得久比赚得快更重要。
