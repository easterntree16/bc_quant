实战策略（二）：趋势跟踪策略——均线交叉、布林带突破

趋势跟踪，说白了就是「顺势而为」。

我个人习惯把这类策略称为「懒人策略」——你不需要预测顶底，只要跟着市场走就行。但别小看它，我在 Hyperliquid 上跑的第一个实盘策略就是均线交叉，结果还挺香的。

一、核心逻辑：为什么趋势能赚钱？

市场不是随机游走的。你想想看，当一群人同时买入时，价格就会惯性上涨。趋势跟踪就是捕捉这种惯性。

两个经典方法：

  • 均线交叉：快线上穿慢线 → 做多；下穿 → 做空
  • 布林带突破：价格突破上轨 → 做多；跌破下轨 → 做空

核心假设：趋势一旦形成，会持续一段时间。

嗯，这里要注意：震荡行情里这两个策略会频繁打脸。我刚开始做的时候，在横盘期亏了不少手续费。

二、均线交叉策略实现

先看代码，再讲细节。

import pandas as pd
import numpy as np
from hyperliquid import HyperliquidClient

class MovingAverageCrossStrategy:
    def __init__(self, client, symbol, fast_period=5, slow_period=20):
        self.client = client
        self.symbol = symbol
        self.fast_period = fast_period
        self.slow_period = slow_period
        self.position = 0  # 0: 空仓, 1: 多头, -1: 空头
        
    def calculate_ma(self, data, period):
        return data['close'].rolling(window=period).mean()
    
    def generate_signal(self, data):
        fast_ma = self.calculate_ma(data, self.fast_period)
        slow_ma = self.calculate_ma(data, self.slow_period)
        
        # 获取最新两根K线的均线值
        current_fast = fast_ma.iloc[-1]
        current_slow = slow_ma.iloc[-1]
        prev_fast = fast_ma.iloc[-2]
        prev_slow = slow_ma.iloc[-2]
        
        # 金叉：快线上穿慢线
        if prev_fast <= prev_slow and current_fast > current_slow:
            return 1  # 买入信号
        # 死叉：快线下穿慢线
        elif prev_fast >= prev_slow and current_fast < current_slow:
            return -1  # 卖出信号
        else:
            return 0  # 无信号
    
    def execute_trade(self, signal, size=0.01):
        if signal == 1 and self.position != 1:
            # 平空开多
            if self.position == -1:
                self.client.close_position(self.symbol)
            self.client.market_order(self.symbol, 'buy', size)
            self.position = 1
            print(f"开多 {self.symbol}，数量 {size}")
            
        elif signal == -1 and self.position != -1:
            # 平多开空
            if self.position == 1:
                self.client.close_position(self.symbol)
            self.client.market_order(self.symbol, 'sell', size)
            self.position = -1
            print(f"开空 {self.symbol}，数量 {size}")

避坑指南：我曾经直接用市价单开仓，结果在流动性差的时候滑点吃了大亏。建议用限价单或者加个滑点保护。

三、布林带突破策略实现

布林带的核心是「均值回归」和「趋势突破」的结合。当价格突破上轨，说明多头力量强，可能开启新趋势。

class BollingerBandStrategy:
    def __init__(self, client, symbol, period=20, std_dev=2):
        self.client = client
        self.symbol = symbol
        self.period = period
        self.std_dev = std_dev
        self.position = 0
        
    def calculate_bollinger(self, data):
        close = data['close']
        sma = close.rolling(window=self.period).mean()
        std = close.rolling(window=self.period).std()
        
        upper_band = sma + (std * self.std_dev)
        lower_band = sma - (std * self.std_dev)
        
        return upper_band, sma, lower_band
    
    def generate_signal(self, data):
        upper, middle, lower = self.calculate_bollinger(data)
        current_price = data['close'].iloc[-1]
        prev_price = data['close'].iloc[-2]
        
        # 突破上轨做多
        if prev_price <= upper.iloc[-2] and current_price > upper.iloc[-1]:
            return 1
        # 跌破下轨做空
        elif prev_price >= lower.iloc[-2] and current_price < lower.iloc[-1]:
            return -1
        else:
            return 0

注意：布林带参数不能死板。我在 BTC 上用的 20 周期 2 倍标准差，在 ETH 上就得调成 15 周期 2.5 倍。不同品种波动性不一样。

四、策略对比与选择

策略 优点 缺点 适用场景
均线交叉 简单稳定，趋势明显时表现好 滞后性强，震荡市频繁亏损 大级别趋势行情（4H以上）
布林带突破 捕捉爆发点，入场时机更早 假突破多，需要过滤 波动率放大阶段

我个人习惯把两者结合：先用布林带识别突破，再用均线确认趋势方向。比如价格突破上轨 + 快线在慢线上方，才开多单。

六、实战中的坑与优化

  1. 参数过拟合：别在历史数据上反复调参。我见过有人把回测做到年化500%，实盘一周爆仓。
  2. 手续费吞噬：Hyperliquid 手续费虽然低，但高频交易还是扛不住。建议至少用15分钟以上周期。
  3. 假突破过滤：加个成交量确认。如果突破时成交量没放大，大概率是假突破。

我的小技巧：在 Hyperliquid 上跑策略时，我会同时监控资金费率。如果资金费率异常偏高，说明市场情绪极端，这时候趋势策略要格外小心。
