实战策略（一）：网格交易策略——原理、实现、回测

网格交易，说白了就是「低买高卖」的机械化版本。你设定好价格区间，系统自动在低位买入、高位卖出。听起来简单？嗯，确实简单。但越简单的东西，往往越容易在细节上翻车。

我个人习惯把网格交易比作「渔网捕鱼」。你把网撒下去，鱼（利润）自己会撞进来。你不需要预测鱼什么时候来，只需要保证网没破、网眼大小合适。

网格交易的核心原理

网格策略的本质，就是利用市场的震荡来赚钱。它不关心趋势，只关心波动。你想想看，如果价格在一个区间内来回震荡，你每次低买高卖都能赚到差价。

具体来说，你需要做三件事：

  • 划定价格区间：比如 BTC 在 60000 到 70000 之间震荡
  • 设定网格数量：分成 10 格，每格 1000 美元
  • 分配资金：每格放一份资金，价格跌到某格就买入，涨到上一格就卖出

举个例子：

价格区间 网格数 每格价差 初始资金
60000 - 70000 10 1000 10000 USDT

当价格从 65000 跌到 64000，系统自动买入。等价格回到 65000，系统自动卖出。一来一回，赚了 1000 美元的差价（扣除手续费后）。

关键点：网格交易不预测方向。它只做一件事——在震荡中收割利润。趋势行情里网格会失效，这点后面我会细说。

网格策略的数学期望

你可能会问：「网格交易真的能赚钱吗？」

答案是：能，但有前提。网格的盈利来自于市场的波动率。波动越大，网格成交越频繁，利润越高。但波动太大，价格突破区间，你就被套了。

我做过一个统计：

市场状态 网格表现 年化收益（回测）
震荡市（±10%） 优秀 15% - 30%
单边上涨 跑输持有 5% - 10%
单边下跌 亏损 -10% 到 -20%

说白了，网格交易就是「赚波动的钱，亏趋势的钱」。所以选对市场环境很重要。

Python 实现：一个简单的网格引擎

下面是我写的一个轻量级网格引擎。代码不长，但核心逻辑都在里面了。

class GridTrader:
    def __init__(self, lower_price, upper_price, grid_count, total_capital):
        self.lower = lower_price
        self.upper = upper_price
        self.grid_count = grid_count
        self.grid_size = (upper_price - lower_price) / grid_count
        self.capital = total_capital
        self.position = 0  # 当前持仓数量
        self.grid_levels = []
        self._init_grids()
    
    def _init_grids(self):
        """初始化网格价格水平"""
        for i in range(self.grid_count + 1):
            price = self.lower + i * self.grid_size
            self.grid_levels.append(price)
    
    def on_price_update(self, current_price):
        """价格更新时触发"""
        # 找到当前价格所在的网格区间
        grid_index = int((current_price - self.lower) / self.grid_size)
        grid_index = max(0, min(grid_index, self.grid_count - 1))
        
        # 检查是否需要买入或卖出
        lower_bound = self.grid_levels[grid_index]
        upper_bound = self.grid_levels[grid_index + 1]
        
        # 如果价格跌破下边界，买入
        if current_price <= lower_bound and self.capital > 0:
            buy_amount = self.capital / (self.grid_count - grid_index)
            self.position += buy_amount / current_price
            self.capital -= buy_amount
            print(f"买入: {buy_amount:.2f} USDT @ {current_price:.2f}")
        
        # 如果价格突破上边界，卖出
        elif current_price >= upper_bound and self.position > 0:
            sell_amount = self.position * current_price
            self.capital += sell_amount
            self.position = 0
            print(f"卖出: {sell_amount:.2f} USDT @ {current_price:.2f}")
    
    def get_pnl(self, current_price):
        """计算当前盈亏"""
        total_value = self.capital + self.position * current_price
        return total_value - self.initial_capital

个人经验：我在实际项目中遇到过一个问题——网格的触发频率太高，导致手续费吃掉所有利润。后来我加了一个「最小价差」参数，只有价格波动超过一定比例才触发交易。效果立竿见影。

回测框架：验证你的网格策略

写代码只是第一步。你得回测，看看历史数据里这个策略表现如何。我习惯用 Pandas 做回测，简单直接。

import pandas as pd
import numpy as np

def backtest_grid(data, lower, upper, grid_count, capital):
    """
    网格策略回测
    data: DataFrame，包含 'close' 列
    """
    trader = GridTrader(lower, upper, grid_count, capital)
    equity_curve = []
    
    for price in data['close']:
        trader.on_price_update(price)
        equity = trader.get_pnl(price)
        equity_curve.append(equity)
    
    data['equity'] = equity_curve
    return data

# 加载历史数据
df = pd.read_csv('btc_1h_data.csv')
result = backtest_grid(df, 60000, 70000, 10, 10000)

# 计算关键指标
total_return = result['equity'].iloc[-1]
max_drawdown = (result['equity'].cummax() - result['equity']).max()
sharpe_ratio = result['equity'].pct_change().mean() / result['equity'].pct_change().std() * np.sqrt(365*24)

print(f"总收益: {total_return:.2f} USDT")
print(f"最大回撤: {max_drawdown:.2f} USDT")
print(f"夏普比率: {sharpe_ratio:.2f}")

避坑指南：我曾经在回测里犯过一个低级错误——没有考虑手续费。结果实盘跑起来，利润全被手续费吃掉了。记住，回测一定要加上手续费和滑点，否则结果就是「纸上富贵」。

网格策略的优化方向

基础网格能赚钱，但想赚更多，你得优化。我总结了几条经验：

  • 动态调整网格区间：根据波动率自动调整上下边界。波动大时放宽区间，波动小时收窄。
  • 非等距网格：价格低的时候网格密一些，价格高的时候疏一些。因为低价位波动百分比更大。
  • 加入止损机制：当价格突破区间一定比例时，清仓止损。别让单边行情把你拖死。
  • 多币种网格：同时跑多个币种的网格，分散风险。但注意相关性，别全买同一板块的币。

我个人习惯用「波动率自适应网格」。具体做法是：用过去 N 天的 ATR（平均真实波幅）来动态调整网格间距。波动率高了，网格间距拉大，减少无效交易；波动率低了，网格间距缩小，增加交易频率。

网格策略的适用场景

网格交易不是万能的。它最适合以下场景：

  • 震荡市：价格在一个区间内来回波动，网格能反复收割
  • 低波动率：波动率越低，网格的胜率越高
  • 高流动性：流动性差的币种，滑点会吃掉利润
  • 低手续费：手续费越低，网格越容易盈利

反过来，单边趋势行情里，网格就是「接飞刀」。价格一路下跌，你一路买入，最后满仓被套。所以，网格交易一定要配合趋势判断，或者设置硬止损。

核心总结：网格交易是「赚波动的钱」。它不预测方向，只利用震荡。回测时一定要考虑手续费和滑点。优化方向包括动态区间、非等距网格和止损机制。
