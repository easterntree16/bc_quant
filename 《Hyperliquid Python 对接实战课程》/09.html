下单操作（一）：限价单与市价单的区别、下单参数详解、构建下单请求

好，我们正式开始讲下单了。

说实话，很多新手一上来就问：「我该用限价单还是市价单？」这个问题其实没有标准答案。我个人习惯是：看场景。你想想看，如果你急着进场，市价单肯定快；但如果你对价格敏感，限价单才是你的朋友。

限价单 vs 市价单：本质区别

先给个最直白的定义：

  • 限价单（Limit Order）：你指定一个价格，只有市场价到了这个位置才成交。说白了，你是「守株待兔」。
  • 市价单（Market Order）：你不指定价格，系统直接按当前最优价帮你吃掉对手盘。你是「冲进去抢」。

我在项目中遇到过不少新手，上来就无脑用市价单，结果在流动性差的币种上被滑点吃掉好几个点。嗯，这里要注意：市价单不是「免费」的，它的成本体现在滑点上。

核心区别总结

维度 限价单 市价单
价格控制 完全由你指定 由市场决定
成交速度 可能不成交 几乎立即成交
滑点风险 无滑点 有滑点
适用场景 挂单做市、精准入场 快速建仓、止损

下单参数详解

Hyperliquid 的下单接口，参数其实不多，但每个都很关键。我带你过一遍：

  • coin：交易对，比如 "BTC"、"ETH"。注意是字符串，不是合约名称。
  • is_buy：布尔值。True 表示买入（做多），False 表示卖出（做空）。
  • sz：数量。单位是币的数量，不是张数。比如 0.1 表示 0.1 个 BTC。
  • limit_px：限价单的价格。如果是市价单，传 0 或者不传。
  • order_type：订单类型。我常用的有：
    • {"limit": {"tif": "Gtc"}} — 普通限价单，一直有效直到成交或取消
    • {"limit": {"tif": "Ioc"}} — 立即成交否则取消
    • {"market": {}} — 市价单
  • reduce_only：是否只减仓。做对冲时很有用，防止不小心开反方向。

我的小技巧：我个人习惯把 order_type 单独封装成一个函数，这样代码更干净。你想想看，如果每次下单都要手写那个嵌套字典，多容易出错。

import requests

class HyperliquidOrder:

        self.base_url = "https://api.hyperliquid.xyz"
    
    def place_order(self, coin, is_buy, sz, limit_px=0, order_type="market", reduce_only=False):
        """
        构建并发送下单请求
        """
        # 1. 构建订单参数
        if order_type == "market":
            order_type_dict = {"market": {}}
        elif order_type == "limit_gtc":
            order_type_dict = {"limit": {"tif": "Gtc"}}
        elif order_type == "limit_ioc":
            order_type_dict = {"limit": {"tif": "Ioc"}}
        else:
            raise ValueError(f"不支持的订单类型: {order_type}")
        
        # 2. 构建请求体
        order_data = {
            "coin": coin,
            "is_buy": is_buy,
            "sz": sz,
            "limit_px": limit_px,
            "order_type": order_type_dict,
            "reduce_only": reduce_only

实际调用示例

假设你想以市价买入 0.5 个 BTC，代码是这样的：

# 初始化订单管理器
order_mgr = HyperliquidOrder(private_key="你的私钥", account_address="你的地址")

# 市价买入 0.5 BTC
result = order_mgr.place_order(
    coin="BTC",
    is_buy=True,
    sz=0.5,
    order_type="market"
)

print(result)
# 输出示例：
# {"response": {"type": "order", "data": {"oid": 123456, "status": "filled"}}}

如果你想挂一个限价单，在 30000 美元的位置买入 0.1 个 ETH：

result = order_mgr.place_order(
    coin="ETH",
    is_buy=True,
    sz=0.1,
    limit_px=30000,
    order_type="limit_gtc"
)

经验之谈：我个人建议，在测试网阶段，把所有订单类型都跑一遍。尤其是 IOC 订单，很多人以为它和市价单一样，其实区别很大。IOC 是「能成交多少就成交多少，剩下的取消」，而市价单是「吃光所有对手盘直到数量满足」。这两个在流动性不足时表现完全不同。
