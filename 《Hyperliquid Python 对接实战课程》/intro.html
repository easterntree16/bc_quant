课程大纲 · 30 大章节，体系化进阶
  • Hyperliquid 生态概览 什么是 Hyperliquid、去中心化衍生品交易的核心逻辑、为什么选择 Python 对接。
  • 环境准备 Python 3.10+ 安装、虚拟环境配置、pip 换源、常用依赖库安装（requests, websockets, eth_account）。
  • Hyperliquid API 基础 REST API 与 WebSocket API 的区别、API 文档速览、获取公开市场数据。
  • 账户与钱包 以太坊钱包生成、私钥管理、助记词导入、本地签名环境搭建。
  • 签名机制详解 EIP-712 结构化数据签名、TypedData 构建、eth_signTypedData_v4 实现。
  • REST API 实战（一） 获取订单簿深度、获取 K 线数据、获取交易历史。
  • REST API 实战（二） 获取账户余额、获取持仓信息、获取未成交订单。
  • REST API 实战（三） 获取资金费率、获取指数价格、获取市场状态。
  • 下单操作（一） 限价单与市价单的区别、下单参数详解、构建下单请求。
  • 下单操作（二） 签名并发送订单、订单状态轮询、订单取消与修改。
  • 下单操作（三） 止损单、止盈单、追踪止损单的实现。
  • WebSocket 基础 WebSocket 连接建立、心跳维持、订阅与取消订阅。
  • WebSocket 实战（一） 实时订单簿数据流、增量更新与全量快照。
  • WebSocket 实战（二） 实时成交数据流、用户订单状态推送。
  • WebSocket 实战（三） 实时账户余额与持仓更新、资金费率推送。
  • 错误处理与重试机制 HTTP 错误码处理、WebSocket 断线重连、指数退避策略。
  • 日志与监控 Python logging 配置、关键操作日志记录、异常告警集成。
  • 性能优化 连接池管理、请求并发控制、数据缓存策略。
  • 策略框架搭建（一） 策略基类设计、回测与实盘模式切换。
  • 策略框架搭建（二） 信号生成模块、风险管理模块、订单执行模块。
  • 策略框架搭建（三） 多时间周期分析、资金管理、仓位管理。
  • 实战策略（一） 网格交易策略——原理、实现、回测。
  • 实战策略（二） 趋势跟踪策略——均线交叉、布林带突破。
  • 实战策略（三） 套利策略——跨期套利、资金费率套利。
  • 实战策略（四） 做市商策略——双边报价、库存管理。
  • 数据存储与分析 使用 SQLite 存储历史数据、Pandas 数据分析、可视化。
  • 安全最佳实践 私钥加密存储、环境变量管理、API 权限最小化。
  • 部署与运维 Linux 服务器部署、Supervisor 进程管理、Docker 容器化。
  • 测试与调试 单元测试、模拟交易环境、回测引擎集成。
  • 项目实战 从零搭建一个完整的 Hyperliquid 量化交易机器人——需求分析、架构设计、编码实现、部署上线。
