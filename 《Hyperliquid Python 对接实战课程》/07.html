REST API 实战（二）：账户余额、持仓与未成交订单

好，咱们接着聊。上一节我们把 API 的基础通信搭好了，拿到了一个简单的测试结果。今天要干点真活——查账户余额、看持仓、还有那些挂出去没成交的单子。

这三个接口，说白了就是交易员的「仪表盘」。你想想看，做量化交易，第一件事就是知道自己有多少子弹、仓位情况怎么样、还有哪些单子挂在市场上没动。没有这些信息，你就是在闭着眼睛交易。

1. 获取账户余额

先看余额接口。Hyperliquid 的余额查询，返回的是你账户里所有资产的信息。我个人习惯在每次交易前都先拉一次余额，确保资金足够，避免下单时被拒。

接口路径是 /info，请求类型是 POST，但注意——它用的是 POST 请求来查询信息，不是 GET。我第一次对接时还愣了一下，心想怎么查询也用 POST？后来发现这是 Hyperliquid 的设计风格，所有请求统一走 POST，省得搞混。

来看代码：

import requests
import json

BASE_URL = "https://api.hyperliquid.xyz"

def get_account_balance(address):
    """获取账户余额"""
    payload = {
        "type": "clearinghouseState",
        "user": address
    }
    
    headers = {
        "Content-Type": "application/json"
    }
    
    response = requests.post(
        f"{BASE_URL}/info",
        data=json.dumps(payload),
        headers=headers
    )
    
    if response.status_code == 200:
        return response.json()
    else:
        print(f"请求失败: {response.status_code}")
        return None

# 使用示例
address = "0x你的钱包地址"
balance_data = get_account_balance(address)
print(json.dumps(balance_data, indent=2))

返回的数据结构大概是这样的：

{
    "assetPositions": [],
    "crossMarginSummary": {
        "accountValue": "10000.0",
        "totalMarginUsed": "0.0",
        "totalNtlPos": "0.0",
        "totalRawUsd": "10000.0"
    },
    "marginSummary": {
        "accountValue": "10000.0",
        "totalMarginUsed": "0.0",
        "totalNtlPos": "0.0",
        "totalRawUsd": "10000.0"
    },
    "time": 1234567890,
    "withdrawable": "10000.0"
}

关键字段说明：

  • accountValue：账户总价值（含未实现盈亏）
  • totalMarginUsed：已使用的保证金
  • withdrawable：可提现金额
  • assetPositions：持仓列表（后面会讲）

💡 小技巧：withdrawable 这个字段特别有用。我在做风控系统时，直接用这个值来判断还能不能开新仓，省得自己算一遍。

2. 获取持仓信息

持仓信息其实就在刚才的余额接口里——assetPositions 字段。但为了清晰，我一般单独封装一个函数来解析它。

为什么会这样设计？因为 Hyperliquid 把余额和持仓放在同一个响应里，减少了一次网络请求。嗯，这里要注意，如果你只想要持仓，还是得调同一个接口，然后自己过滤。

def get_positions(address):
    """获取当前持仓"""
    balance_data = get_account_balance(address)
    if not balance_data:
        return []
    
    positions = balance_data.get("assetPositions", [])
    parsed_positions = []
    
    for pos in positions:
        # 每个持仓包含 position 和 type 两个字段
        position_info = pos.get("position", {})
        parsed_positions.append({
            "coin": position_info.get("coin"),
            "size": position_info.get("szi"),  # 带符号的持仓量
            "entry_price": position_info.get("entryPx"),
            "unrealized_pnl": position_info.get("unrealizedPnl"),
            "liquidation_price": position_info.get("liquidationPx"),
            "leverage": position_info.get("leverage", {}).get("value")
        })
    
    return parsed_positions

# 使用示例
positions = get_positions(address)
for pos in positions:
    print(f"{pos['coin']}: 持仓 {pos['size']}, 开仓价 {pos['entry_price']}")

⚠️ 注意：szi 字段是带符号的。正数表示多头，负数表示空头。我曾经在写策略时忘了处理符号，结果把空头当多头算，差点爆仓。

持仓数据里还有一个很重要的字段——liquidationPrice。这个就是你的爆仓价。我个人习惯在每次拿到持仓后，都检查一下当前价格离爆仓价有多远。如果太近，就得考虑减仓或者加保证金了。

3. 获取未成交订单

未成交订单，也叫「挂单」或「Open Orders」。这个接口单独走 /info 的另一个类型。

def get_open_orders(address):
    """获取未成交订单"""
    payload = {
        "type": "openOrders",
        "user": address
    }
    
    response = requests.post(
        f"{BASE_URL}/info",
        data=json.dumps(payload),
        headers={"Content-Type": "application/json"}
    )
    
    if response.status_code == 200:
        return response.json()
    else:
        print(f"请求失败: {response.status_code}")
        return []

# 使用示例
orders = get_open_orders(address)
for order in orders:
    print(f"订单 {order['oid']}: {order['coin']} {order['side']} {order['sz']} @ {order['limitPx']}")

返回的每个订单包含这些信息：

字段 说明 示例
oid 订单ID 123456789
coin 交易对 BTC
side 买卖方向 B / A
sz 订单数量 0.1
limitPx 限价价格 50000.0
orderType 订单类型 Limit / Ioc
timestamp 下单时间 1234567890

实战经验：我在做网格交易策略时，每5秒拉一次未成交订单，检查哪些单子还没成交。如果某个订单挂了太久（比如超过10分钟），我会先撤单，然后重新挂一个更优的价格。这样能提高成交率，避免价格跑了单子还挂在那。

4. 整合：一个完整的账户监控函数

把上面三个功能整合到一起，写一个监控函数。这样你跑策略时，一个调用就能拿到所有关键信息。

def monitor_account(address):
    """监控账户状态"""
    print("=" * 50)
    print("账户监控报告")
    print("=" * 50)
    
    # 1. 余额
    balance = get_account_balance(address)
    if balance:
        summary = balance.get("crossMarginSummary", {})
        print(f"\n💰 账户总价值: {summary.get('accountValue')} USD")
        print(f"💸 可提现金额: {balance.get('withdrawable')} USD")
    
    # 2. 持仓
    positions = get_positions(address)
    if positions:
        print(f"\n📊 当前持仓 ({len(positions)} 个):")
        for pos in positions:
            pnl = float(pos['unrealized_pnl'])
            pnl_str = f"+{pnl}" if pnl >= 0 else str(pnl)
            print(f"  {pos['coin']}: {pos['size']} 张 | 盈亏: {pnl_str} USD")
    else:
        print("\n📊 当前无持仓")
    
    # 3. 未成交订单
    orders = get_open_orders(address)
    if orders:
        print(f"\n📋 未成交订单 ({len(orders)} 个):")
        for order in orders:
            print(f"  #{order['oid']}: {order['coin']} {order['side']} {order['sz']} @ {order['limitPx']}")
    else:
        print("\n📋 无未成交订单")
    
    print("=" * 50)

# 使用示例
monitor_account(address)
