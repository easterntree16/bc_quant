第22章：链上指标构建

说实话，链上数据就像一座金矿。但光有数据没用，你得知道怎么提炼。我见过太多人盯着Hyperliquid的原始数据发呆，却不知道从何下手。今天我就带你把这四个核心指标给搭起来。

22.1 活跃地址指标

活跃地址，说白了就是链上到底有多少人在动。这个指标我几乎每天都会看，它直接反映了网络的使用热度。

核心定义：在特定时间窗口内（通常24小时），至少参与过一次交易的唯一地址数量。

我在构建这个指标时，通常会分三层来算：

// 基础活跃地址（24h内有过任何交易）
SELECT COUNT(DISTINCT sender) + COUNT(DISTINCT receiver) 
FROM transactions 
WHERE timestamp > NOW() - INTERVAL '24 hours'

// 交易活跃地址（24h内发起过交易）
SELECT COUNT(DISTINCT sender) 
FROM transactions 
WHERE timestamp > NOW() - INTERVAL '24 hours'

// 合约交互活跃地址（24h内调用过合约）
SELECT COUNT(DISTINCT sender) 
FROM transactions 
WHERE type = 'contract_call' 
AND timestamp > NOW() - INTERVAL '24 hours'

嗯，这里要注意一个坑。我曾经在分析Hyperliquid的活跃地址时，发现数据突然暴涨。后来一查，原来是某个做市商的批量转账脚本在跑。所以单纯看总数会失真，我建议你同时看「去重后的真实用户数」。

我的经验：活跃地址的7日移动平均线比单日数据更有参考价值。它能过滤掉周末效应和偶发事件的影响。

22.2 网络价值指标

网络价值，就是整个链上生态到底值多少钱。这个指标我一般从三个维度来构建：

指标名称 计算方式 说明
总锁仓价值（TVL） ∑(各协议锁仓资产 × 当前价格) 反映资金沉淀深度
网络总价值（NV） 流通市值 + TVL 综合衡量网络规模
价值密度 NV / 活跃地址数 每个用户贡献的价值

我个人习惯把TVL拆开来看。Hyperliquid上的永续合约、现货、借贷，每个模块的TVL意义完全不同。合约的TVL高说明杠杆需求旺盛，借贷的TVL高则说明资金效率在提升。

// 计算Hyperliquid各模块TVL
SELECT 
    protocol,
    SUM(amount * price_usd) as tvl
FROM positions
WHERE chain = 'hyperliquid'
GROUP BY protocol
ORDER BY tvl DESC

避坑指南：我曾经直接用Dune的数据算TVL，结果发现和官方数据对不上。后来才明白，Hyperliquid的跨链桥资产需要单独处理，否则会重复计算。记得把跨链桥的锁仓量排除掉。

22.3 流动性指标

流动性是DeFi的命脉。在Hyperliquid上，我主要关注这几个流动性指标：

  • 订单簿深度：买卖盘口各1%深度内的挂单总量
  • 滑点成本：交易1万美元市价单的预期滑点
  • 资金费率：永续合约的资金费率，反映多空力量
  • 价差：买卖价差，越窄说明流动性越好

你想想看，如果一个交易对深度好但滑点高，说明什么？说明挂单分布不均匀。我遇到过这种情况，表面看深度有500万，但实际一吃单，价格直接滑了0.5%。所以深度和滑点要结合起来看。

// 计算订单簿深度（以BTC为例）
WITH orderbook AS (
    SELECT 
        side,
        price,
        amount
    FROM hyperliquid_orderbook
    WHERE pair = 'BTC/USDC'
)
SELECT 
    side,
    SUM(amount) as total_amount,
    AVG(price) as avg_price
FROM orderbook
WHERE 
    (side = 'bid' AND price >= (SELECT MAX(price) * 0.99 FROM orderbook WHERE side = 'bid'))
    OR 
    (side = 'ask' AND price <= (SELECT MIN(price) * 1.01 FROM orderbook WHERE side = 'ask'))
GROUP BY side

小技巧：我习惯用「流动性得分」来综合评估。公式是：深度得分 × 0.4 + 滑点得分 × 0.3 + 价差得分 × 0.3。这样能快速对比不同交易对的流动性质量。

22.4 市场情绪指标

情绪指标最难量化，但也最有用。我构建了一套组合指标：

  1. 资金流向比：净流入资金 / 总交易量。比值大于0.1说明看多情绪强
  2. 多空比：多头持仓量 / 空头持仓量。极端值往往预示反转
  3. 持仓集中度：前10大地址持仓占比。占比过高说明筹码集中
  4. 换手率：24小时交易量 / 流通市值。换手率突然飙升要警惕

我记得有一次，Hyperliquid上的ETH多空比达到了3:1，我当时就觉得不对劲。果然，第二天就来了个20%的暴跌。为什么？因为当所有人都看多的时候，已经没有新的资金进场了。

// 计算多空比
SELECT 
    pair,
    SUM(CASE WHEN side = 'long' THEN size ELSE 0 END) as long_volume,
    SUM(CASE WHEN side = 'short' THEN size ELSE 0 END) as short_volume,
    SUM(CASE WHEN side = 'long' THEN size ELSE 0 END) / 
    NULLIF(SUM(CASE WHEN side = 'short' THEN size ELSE 0 END), 0) as long_short_ratio
FROM hyperliquid_positions
WHERE timestamp > NOW() - INTERVAL '24 hours'
GROUP BY pair

重要提醒：情绪指标不能单独使用。我曾经只靠多空比做判断，结果在震荡市里被反复打脸。一定要结合价格走势和成交量来看，三者共振时信号才可靠。

好了，这四个指标构建起来后，你就能从不同维度看清Hyperliquid的链上生态了。活跃地址看人气，网络价值看规模，流动性看效率，市场情绪看方向。把它们组合起来，就是一个完整的链上分析框架。

构建这些指标时，我建议你从最简单的开始。先跑通活跃地址，再逐步加上其他指标。别想一口吃成胖子，我当初也是花了两个月才把这套框架打磨成熟。
