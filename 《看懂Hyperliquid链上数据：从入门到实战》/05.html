5、Python环境搭建：从零开始连接HyperLiquid

说实话，很多人在链上数据分析这条路上栽跟头，不是因为技术太难，而是环境没搭好。我见过太多人卡在第一步——装个库报错、RPC连不上、代码跑不起来。今天咱们就把这事彻底搞定。

这一章的目标很简单：让你能在自己的电脑上，用Python成功连上HyperLiquid的RPC节点，并且跑通第一个查询脚本。嗯，就这么纯粹。

5.1 Python安装：选对版本省一半力气

我个人习惯用Python 3.10或3.11。为什么？因为Web3.py这个库在3.12上偶尔会闹脾气，我去年踩过这个坑，折腾了两天才发现是版本兼容问题。

安装步骤：

  1. 去 python.org 下载对应系统的安装包
  2. 安装时记得勾选「Add Python to PATH」
  3. 打开终端（Windows用CMD或PowerShell，Mac/Linux用Terminal）
  4. 输入 python --version 确认安装成功
我的小建议： 如果你同时做其他项目，建议用虚拟环境。我一般用 python -m venv hyperliquid_env 创建独立环境，避免库版本冲突。

5.2 Web3.py库安装：一行命令搞定

Web3.py是Python世界连接以太坊系区块链的标配。HyperLiquid虽然是L1，但它的RPC接口兼容以太坊的JSON-RPC规范，所以Web3.py完全能用。

安装命令：

pip install web3

如果你在国内，网络可能有点慢。我曾经被这个卡了半小时，后来换了清华镜像源：

pip install web3 -i https://pypi.tuna.tsinghua.edu.cn/simple

装完之后验证一下：

python -c "from web3 import Web3; print(Web3.__version__)"

如果输出版本号，比如 6.15.1，那就成了。

注意： 有些系统会同时装Python 2和Python 3，这时候要用 pip3 而不是 pip。我刚开始就犯过这个错，装了半天发现Python 2里根本找不到web3。

5.3 连接HyperLiquid RPC：找到正确的入口

HyperLiquid的RPC节点地址是公开的。我个人习惯用主网节点，因为数据实时性最好。

RPC地址：

https://api.hyperliquid.xyz/evm

为什么是这个地址？HyperLiquid的EVM兼容层跑在这个端口上。说白了，你通过这个地址就能像查以太坊一样查HyperLiquid的数据。

写个连接脚本试试：

from web3 import Web3

# 连接RPC
rpc_url = "https://api.hyperliquid.xyz/evm"
w3 = Web3(Web3.HTTPProvider(rpc_url))

# 检查连接状态
if w3.is_connected():
    print("✅ 连接成功！")
    print(f"当前区块高度: {w3.eth.block_number}")
else:
    print("❌ 连接失败，检查网络或RPC地址")

我第一次跑这个脚本时，看到「连接成功」四个字，心里踏实了不少。你想想看，如果连这一步都过不去，后面所有分析都是空中楼阁。

避坑指南： 我曾经遇到过RPC返回超时的情况，原因是本地网络防火墙拦截了HTTPS请求。解决办法是换一个网络环境，或者用 Web3.HTTPProvider(rpc_url, request_kwargs={'timeout': 30}) 设置超时时间。

5.4 第一个查询脚本：获取最新区块信息

好了，环境搭好了，连接也通了。咱们写个正经的查询脚本，获取HyperLiquid的最新区块信息。

完整脚本：

from web3 import Web3
import json

# 配置
RPC_URL = "https://api.hyperliquid.xyz/evm"
w3 = Web3(Web3.HTTPProvider(RPC_URL))

def get_latest_block_info():
    """获取最新区块的详细信息"""
    try:
        # 获取最新区块号
        latest_block = w3.eth.block_number
        print(f"最新区块号: {latest_block}")
        
        # 获取区块详情
        block = w3.eth.get_block(latest_block)
        
        # 提取关键信息
        info = {
            "区块号": block['number'],
            "时间戳": block['timestamp'],
            "交易数量": len(block['transactions']),
            "Gas使用量": block['gasUsed'],
            "Gas上限": block['gasLimit'],
            "区块哈希": block['hash'].hex()[:20] + "..."
        }
        
        print("\n区块详情:")
        for key, value in info.items():
            print(f"  {key}: {value}")
        
        return block
        
    except Exception as e:
        print(f"查询失败: {e}")
        return None

# 执行查询
if __name__ == "__main__":
    print("🔍 正在查询HyperLiquid最新区块...")
    get_latest_block_info()

跑一下看看效果。如果一切正常，你会看到类似这样的输出：

🔍 正在查询HyperLiquid最新区块...
最新区块号: 12345678

区块详情:
  区块号: 12345678
  时间戳: 1712345678
  交易数量: 42
  Gas使用量: 15000000
  Gas上限: 30000000
  区块哈希: 0xabc123def456...

看到这个输出，说明你已经成功连上HyperLiquid，并且拿到了链上数据。这一步，是后面所有分析的基础。

扩展一下： 你可以把 w3.eth.get_block() 换成 w3.eth.get_transaction_count() 查某个地址的交易数，或者用 w3.eth.get_balance() 查余额。这些API都是通用的。
