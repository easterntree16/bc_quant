第十章：资金费率与衍生品数据

永续合约是Hyperliquid生态的核心产品。说实话，很多人一上来就盯着K线看，却忽略了资金费率这个关键指标。我做了三年链上数据分析，可以负责任地告诉你——资金费率才是读懂市场情绪的密码。

10.1 资金费率到底是什么？

永续合约没有到期日，那怎么保证价格跟现货不跑偏？答案就是资金费率。它本质上是一种多空双方定期支付的费用。

简单说：

  • 资金费率 > 0：多头付钱给空头。说明市场偏多，做多的人多
  • 资金费率 < 0：空头付钱给多头。说明市场偏空，做空的人多
  • 资金费率 = 0：多空平衡，市场冷静期

核心公式：

资金费率 = 溢价指数 + clamp(利率 - 溢价指数, 0.05%, -0.05%)

其中溢价指数 = (永续合约价格 - 现货指数价格) / 现货指数价格

嗯，公式看着有点绕。但你只需要记住：资金费率绝对值越大，说明市场越极端。我个人习惯把超过0.1%的费率视为「过热信号」。

10.2 如何获取资金费率数据？

Hyperliquid提供了非常干净的API接口。我直接给你看代码：

import requests
import json

# 获取当前所有永续合约的资金费率
url = "https://api.hyperliquid.xyz/info"
payload = {
    "type": "allMids"
}

response = requests.post(url, json=payload)
data = response.json()

# 解析资金费率
for symbol, info in data.items():
    if 'funding' in info:
        print(f"{symbol}: 资金费率 = {info['funding']}")

这段代码会返回所有交易对的当前资金费率。我在项目中遇到过一个问题——资金费率每8小时更新一次，但API返回的是「当前值」，不是「历史值」。如果你要做回测，记得自己存历史数据。

10.3 解析永续合约的完整数据

光看资金费率还不够。一个完整的永续合约数据包含多个维度：

字段 说明 我的用法
markPx 标记价格 用于计算盈亏的基准价
funding 当前资金费率 判断多空情绪
openInterest 未平仓合约量 看市场总参与度
volume24h 24小时成交量 看流动性是否充足
prevDayPx 前一日收盘价 计算涨跌幅

获取完整数据的代码：

# 获取指定合约的完整信息
payload = {
    "type": "metaAndAssetCtxs"
}

response = requests.post(url, json=payload)
data = response.json()

# 解析BTC永续合约
for asset in data[1]:
    if asset['name'] == 'BTC':
        print(f"标记价格: {asset['markPx']}")
        print(f"资金费率: {asset['funding']}")
        print(f"未平仓量: {asset['openInterest']}")
        print(f"24h成交量: {asset['volume24h']}")

个人经验：我一般会同时监控资金费率和未平仓量。如果资金费率很高但未平仓量在下降，说明多头在平仓离场，这是见顶信号。反过来，资金费率低但未平仓量在涨，可能是主力在悄悄建仓。

10.4 计算多空比

多空比是另一个重要指标。Hyperliquid没有直接提供这个数据，但我们可以通过资金费率反推。

逻辑是这样的：

  • 资金费率 = 多头持仓占比 × 多头支付意愿 - 空头持仓占比 × 空头支付意愿
  • 简化模型：多空比 ≈ (1 + 资金费率) / (1 - 资金费率)
def calculate_long_short_ratio(funding_rate):
    """
    根据资金费率估算多空比
    """
    # 防止除零
    if abs(funding_rate) > 0.01:
        ratio = (1 + funding_rate) / (1 - funding_rate)
        return ratio
    else:
        return 1.0  # 费率接近0时，多空接近平衡

# 示例
btc_funding = 0.0005  # 0.05%
ratio = calculate_long_short_ratio(btc_funding)
print(f"估算多空比: {ratio:.2f}")
# 输出: 估算多空比: 1.10
# 意味着多头比空头多10%

注意：这个计算是简化模型。实际多空比还受杠杆倍数、持仓量等因素影响。我一般把它当作「情绪温度计」而不是精确指标。曾经有一次，我用这个模型算出来多空比是1.5，结果市场马上反转了——因为极端值往往意味着过度拥挤。

10.5 监控爆仓数据

爆仓数据是市场最真实的「疼痛指标」。Hyperliquid的API可以获取历史爆仓记录：

# 获取爆仓数据
payload = {
    "type": "liquidations"
}

response = requests.post(url, json=payload)
liquidations = response.json()

# 分析最近爆仓
for liq in liquidations[:10]:
    print(f"交易对: {liq['coin']}")
    print(f"爆仓数量: {liq['size']}")
    print(f"爆仓价格: {liq['price']}")
    print(f"方向: {'多头' if liq['side'] == 'B' else '空头'}")
    print("---")

爆仓数据能告诉你什么？

  • 大量多头爆仓：说明价格快速下跌，杠杆多头被强平。这往往加速下跌
  • 大量空头爆仓：说明价格快速上涨，空头被强平。这往往加速上涨
  • 爆仓量突然放大：可能是「连环爆仓」的开始，市场进入极端行情

我的实战框架：

1. 资金费率 > 0.1% + 爆仓以多头为主 → 短期见顶概率大

2. 资金费率 < -0.1% + 爆仓以空头为主 → 短期见底概率大

3. 资金费率正常 + 爆仓量突然放大 → 可能是趋势加速信号

避坑指南：我曾经只盯着资金费率做交易，结果亏得很惨。后来发现，资金费率在震荡市里经常给出错误信号。一定要结合未平仓量和爆仓数据一起看。比如资金费率很高，但未平仓量在下降，说明是「虚火」，别追多。
