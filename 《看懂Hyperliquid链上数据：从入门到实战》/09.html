第九章：K线数据获取与处理

K线数据，说白了就是交易市场的「心电图」。我在Hyperliquid上做策略回测时，第一件事就是先把K线数据搞定。没有干净的数据，再牛的策略也是白搭。

这一章，我带你从获取原始数据开始，一步步走到绘制出漂亮的K线图。嗯，都是实战干货。

9.1 获取K线数据

Hyperliquid提供了REST API，我们可以直接拉取K线数据。我个人习惯用Python的requests库，简单粗暴。

import requests
import pandas as pd

# Hyperliquid K线API端点
url = "https://api.hyperliquid.xyz/info"

# 请求参数：获取BTC永续合约的1小时K线
payload = {
    "type": "candleSnapshot",
    "coin": "BTC",
    "interval": "1h",
    "startTime": 1700000000000,  # 毫秒时间戳
    "endTime": 1700100000000
}

response = requests.post(url, json=payload)
data = response.json()
print(f"获取到 {len(data)} 根K线")
小提示：时间戳一定要用毫秒！我刚开始写的时候用了秒，结果拉回来的数据全是乱的。Hyperliquid的API对时间精度要求很严格。

支持的K线周期有：1m、5m、15m、30m、1h、4h、1d、1w。你想想看，做短线用1m或5m，做趋势用1h或4h，看大方向用1d或1w。

9.2 OHLCV数据结构

返回的数据长什么样？我们打印一条看看：

# 查看第一条K线
first_candle = data[0]
print(first_candle)

输出大概是这样的：

{
    "t": 1700000000000,    # 开盘时间（毫秒）
    "o": 42000.5,          # 开盘价
    "h": 42500.0,          # 最高价
    "l": 41800.2,          # 最低价
    "c": 42300.8,          # 收盘价
    "v": 1250.3            # 成交量
}

这就是标准的OHLCV结构。O是Open，H是High，L是Low，C是Close，V是Volume。我在项目中遇到过一个问题：有些交易所的成交量单位不一样，有的用币数，有的用美元。Hyperliquid用的是币数，也就是多少个BTC。

字段 含义 数据类型
t 时间戳（毫秒） 整数
o 开盘价 浮点数
h 最高价 浮点数
l 最低价 浮点数
c 收盘价 浮点数
v 成交量 浮点数

9.3 K线数据存储

数据拉回来了，不能每次都重新拉吧？我建议存到本地。常用的存储方式有两种：CSV文件和SQLite数据库。

9.3.1 存为CSV

# 转换为DataFrame
df = pd.DataFrame(data)
df.columns = ['timestamp', 'open', 'high', 'low', 'close', 'volume']
df['timestamp'] = pd.to_datetime(df['timestamp'], unit='ms')

# 保存到CSV
df.to_csv('hyperliquid_btc_1h.csv', index=False)
print("数据已保存到 hyperliquid_btc_1h.csv")
注意：CSV文件适合小规模数据。如果你要存几年的分钟级K线，文件会变得很大。我曾经存了3年的1分钟K线，CSV文件直接飙到2GB，打开都费劲。

9.3.2 存到SQLite

import sqlite3

# 连接数据库（不存在则自动创建）
conn = sqlite3.connect('hyperliquid_kline.db')
cursor = conn.cursor()

# 创建表
cursor.execute('''
    CREATE TABLE IF NOT EXISTS kline_1h (
        timestamp INTEGER PRIMARY KEY,
        open REAL,
        high REAL,
        low REAL,
        close REAL,
        volume REAL
    )
''')

# 批量插入数据
for candle in data:
    cursor.execute('''
        INSERT OR REPLACE INTO kline_1h 
        VALUES (?, ?, ?, ?, ?, ?)
    ''', (candle['t'], candle['o'], candle['h'], 
          candle['l'], candle['c'], candle['v']))

conn.commit()
conn.close()
print("数据已存入SQLite数据库")

SQLite的好处是查询快，而且不会像CSV那样占用大量内存。我个人的经验是：做回测用SQLite，做快速分析用CSV。

9.4 绘制K线图

数据有了，存好了，接下来就是画图。Python里画K线图最常用的是mplfinance库，它是基于matplotlib的封装，专门为金融数据设计。

9.4.1 安装mplfinance

pip install mplfinance

9.4.2 绘制基础K线图

import mplfinance as mpf

# 准备数据：需要以日期为索引
df['timestamp'] = pd.to_datetime(df['timestamp'], unit='ms')
df.set_index('timestamp', inplace=True)

# 绘制K线图
mpf.plot(
    df,
    type='candle',          # K线类型
    style='charles',        # 配色风格
    title='BTC/USD 1H K线',
    ylabel='价格 (USD)',
    volume=True,            # 显示成交量
    figsize=(12, 8)
)

运行上面的代码，你会看到一张漂亮的K线图。红色是下跌，绿色是上涨。嗯，这是国际惯例。

9.4.3 添加技术指标

光画K线还不够，我们通常要叠加一些指标。比如移动平均线（MA）：

# 计算MA5和MA20
df['ma5'] = df['close'].rolling(window=5).mean()
df['ma20'] = df['close'].rolling(window=20).mean()

# 绘制带MA的K线图
mpf.plot(
    df,
    type='candle',
    style='charles',
    title='BTC/USD 1H K线 (MA5 & MA20)',
    ylabel='价格 (USD)',
    volume=True,
    mav=(5, 20),            # 添加移动平均线
    figsize=(12, 8)
)
避坑指南：我曾经在画图时发现MA线对不上，查了半天才发现是数据没按时间排序。记住，画K线前一定要按时间戳升序排列，否则画出来的图全是乱的。
