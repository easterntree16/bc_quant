17、数据可视化基础：Matplotlib绘制折线图、绘制柱状图、绘制散点图、图表美化技巧

说实话，做链上数据分析这几年，我最大的感触就是：数据本身不会说话，但图表会。你想想看，面对几万行交易记录，谁能一眼看出资金流向的规律？但一张折线图，趋势立马就出来了。

Matplotlib 是 Python 生态里最经典的可视化库。我刚开始用的时候也觉得它丑，后来发现——不是它丑，是我不会打扮它。今天咱们就把它彻底玩明白。

17.1 准备工作：安装与导入

先装好库，这一步没什么好说的：

pip install matplotlib pandas numpy

导入的时候，我个人习惯这样写：

import matplotlib.pyplot as plt
import pandas as pd
import numpy as np

# 让图表在 Jupyter 里直接显示
%matplotlib inline

# 设置中文字体，避免乱码
plt.rcParams['font.sans-serif'] = ['SimHei', 'Arial Unicode MS']
plt.rcParams['axes.unicode_minus'] = False

嗯，这里要注意：中文字体设置是必做的。我曾经在 Mac 上没配好，结果所有标签都变成了小方块，排查了半天才发现是字体问题。

17.2 折线图：看趋势的利器

折线图最适合展示时间序列数据。比如我们分析 Hyperliquid 上某个代币的每日交易量变化：

# 模拟数据：7天的交易量（单位：万美元）
days = ['周一', '周二', '周三', '周四', '周五', '周六', '周日']
volume = [120, 135, 128, 150, 165, 180, 175]

plt.figure(figsize=(10, 5))
plt.plot(days, volume, marker='o', linestyle='-', color='#2196F3', linewidth=2)
plt.title('Hyperliquid 某代币周交易量变化')
plt.xlabel('日期')
plt.ylabel('交易量（万美元）')
plt.grid(True, alpha=0.3)
plt.show()

你看，就这么几行代码，趋势一目了然。周末交易量明显上升，说明散户活跃度在增加。

我的小技巧： marker 参数用 'o' 或 's' 效果最好，别用 '^' 或 'v'，容易跟数据点混淆。

17.3 柱状图：对比数据的首选

柱状图适合分类对比。比如对比不同协议的资金流入量：

# 模拟数据：各协议 TVL（单位：亿美元）
protocols = ['Hyperliquid', 'dYdX', 'GMX', 'Synthetix', 'Perpetual']
tvl = [8.5, 6.2, 4.8, 3.1, 2.5]

plt.figure(figsize=(10, 5))
bars = plt.bar(protocols, tvl, color=['#FF6B6B', '#4ECDC4', '#45B7D1', '#96CEB4', '#FFEAA7'])

# 在柱子上显示数值
for bar in bars:
    height = bar.get_height()
    plt.text(bar.get_x() + bar.get_width()/2., height,
             f'{height}亿', ha='center', va='bottom')

plt.title('各衍生品协议 TVL 对比')
plt.xlabel('协议名称')
plt.ylabel('TVL（亿美元）')
plt.show()

我在项目中遇到过一个问题：柱子颜色太接近，根本分不清。后来我养成了习惯，用一组对比明显的色板，比如上面那套。

避坑指南： 我曾经用默认颜色画了 10 个柱子，结果第 3 和第 4 个颜色几乎一样。建议手动指定颜色，或者用 colormap。

17.4 散点图：发现隐藏的关系

散点图能帮你发现变量之间的相关性。比如分析交易频率和盈亏的关系：

# 模拟数据：100个交易者的数据
np.random.seed(42)
n = 100
trade_count = np.random.randint(1, 50, n)  # 交易次数
profit_rate = np.random.normal(0.05, 0.1, n)  # 收益率
# 加入一些异常值
trade_count[0] = 80
profit_rate[0] = -0.3

plt.figure(figsize=(10, 6))
scatter = plt.scatter(trade_count, profit_rate, 
                     c=profit_rate, cmap='RdYlGn', 
                     alpha=0.6, s=50)

plt.colorbar(scatter, label='收益率')
plt.xlabel('交易次数')
plt.ylabel('收益率')
plt.title('交易频率 vs 收益率 散点图')
plt.axhline(y=0, color='gray', linestyle='--', alpha=0.5)
plt.show()

你发现没有？交易次数适中的用户，收益率反而更高。那些频繁交易的，很多都在亏损。这就是散点图的价值——一眼看出规律。

17.5 图表美化技巧：从能看到好看

说实话，Matplotlib 默认的图表确实丑。但别急，我总结了几个立竿见影的美化技巧：

17.5.1 配色方案

别用默认的蓝色红色了。试试这些：

  • 科技蓝： #2196F3, #1976D2, #0D47A1
  • 暖色系： #FF6B6B, #FFA726, #FFCC80
  • 冷色系： #4ECDC4, #45B7D1, #96CEB4
  • 渐变色： 用 cmap 参数，比如 'viridis', 'plasma', 'RdYlGn'

17.5.2 样式设置

# 使用内置样式
plt.style.use('seaborn-v0_8-darkgrid')
# 或者
plt.style.use('ggplot')

# 自定义样式
plt.rcParams.update({
    'figure.facecolor': 'white',
    'axes.facecolor': '#f5f5f5',
    'axes.grid': True,
    'grid.alpha': 0.3,
    'axes.spines.top': False,
    'axes.spines.right': False,
})

我个人最喜欢 'seaborn-v0_8-darkgrid'，背景有网格线，数据点更突出。

17.5.3 字体与标签

  • 标题： fontsize=16, fontweight='bold'
  • 轴标签： fontsize=12
  • 刻度标签： fontsize=10
  • 图例： loc='best', frameon=False

17.5.4 组合图表：一图多信息

fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# 左上：折线图
axes[0, 0].plot(days, volume, marker='o', color='#2196F3')
axes[0, 0].set_title('交易量趋势')

# 右上：柱状图
axes[0, 1].bar(protocols, tvl, color='#FF6B6B')
axes[0, 1].set_title('TVL 对比')

# 左下：散点图
axes[1, 0].scatter(trade_count, profit_rate, alpha=0.6)
axes[1, 0].set_title('交易频率 vs 收益率')

# 右下：饼图
sizes = [35, 25, 20, 15, 5]
labels = ['Hyperliquid', 'dYdX', 'GMX', 'Synthetix', '其他']
axes[1, 1].pie(sizes, labels=labels, autopct='%1.1f%%')
axes[1, 1].set_title('市场份额')

plt.tight_layout()
plt.show()
核心要点： 图表美化的本质是减少视觉噪音，突出数据信息。去掉不必要的边框、网格线调淡、颜色统一、字体清晰——做到这四点，你的图表就已经超过 80% 的人了。

17.6 实战：Hyperliquid 链上数据可视化

最后，咱们来一个完整的实战案例。假设你从链上拿到了 Hyperliquid 的每日交易数据：

# 模拟真实数据
dates = pd.date_range('2024-01-01', periods=30, freq='D')
data = {
    '交易量': np.random.randint(100, 300, 30),
    '活跃地址': np.random.randint(500, 1500, 30),
    '手续费收入': np.random.uniform(10, 50, 30)
}
df = pd.DataFrame(data, index=dates)

# 创建图表
fig, ax1 = plt.subplots(figsize=(12, 6))

# 左轴：交易量（柱状图）
color1 = '#2196F3'
ax1.bar(df.index, df['交易量'], color=color1, alpha=0.7, label='交易量')
ax1.set_ylabel('交易量（万美元）', color=color1)
ax1.tick_params(axis='y', labelcolor=color1)

# 右轴：活跃地址（折线图）
ax2 = ax1.twinx()
color2 = '#FF6B6B'
ax2.plot(df.index, df['活跃地址'], color=color2, marker='o', label='活跃地址')
ax2.set_ylabel('活跃地址数', color=color2)
ax2.tick_params(axis='y', labelcolor=color2)

# 美化
plt.title('Hyperliquid 1月链上数据概览', fontsize=16, fontweight='bold')
fig.autofmt_xdate()
plt.grid(True, alpha=0.3)

# 合并图例
lines1, labels1 = ax1.get_legend_handles_labels()
lines2, labels2 = ax2.get_legend_handles_labels()
ax1.legend(lines1 + lines2, labels1 + labels2, loc='upper left')

plt.show()

你看，双轴图表能同时展示交易量和活跃地址两个维度的数据。我经常用这种方式来分析链上活动——量价配合，才能看清全貌。

避坑指南： 双轴图表要注意两个轴的刻度范围，别让一条线压扁了另一条。我一般会手动调整 ylim，让两条曲线在视觉上平衡。

好了，这一章的内容就到这里。Matplotlib 的核心就四个字：数据 + 美学。先把数据画对，再慢慢调样式。别一上来就追求花哨，清晰才是第一位的。
